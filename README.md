## What is PulseCommunity?

PulseCommunity is not just another web app.  
It’s a data-driven civic awareness system that empowers users with:

- Interactive Maps  
- Crime Heatmaps  
- Real-time News  
- Public Chat System  
- Weather Insights  
- Announcements System  
- Admin Control Panel
